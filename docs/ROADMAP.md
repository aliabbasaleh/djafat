### Pour que l'API tourne à 100 % (pas juste en démo)

Techniquement terminé ; chaque ligne n'attend plus qu'un accès externe (aucun code à écrire) :

- [ ] **Numéros marchands réels** Airtel Money / Tigo Cash / Moov Money — remplacer les factices (`+23560000010/20/30`) dans `MOBILE_MONEY_WALLETS` de `.env.prod`. Un changement de configuration, zéro ligne de code (même mécanisme générique, prouvé ce soir avec les 3 opérateurs).
- [ ] **Fournisseur SMS réel** (Tchad) — `SMS_PROVIDER=http` + `SMS_HTTP_URL`/`SMS_HTTP_API_KEY` dans `.env.prod`. Aujourd'hui les codes arrivent dans une boîte de test interne au serveur (mode démo), jamais par vrai SMS.
- [ ] **WhatsApp Business réel** (compte Meta vérifié, numéro à choisir) — `WHATSAPP_PROVIDER=cloud` + les identifiants Meta. Le code existe déjà en entier : depuis la 0.29.0 (FEAT-023), le client envoie le code affiché et DJAFAT n'envoie rien, donc aucun message payant chez Meta ; guide pas à pas dans `docs/39` §3, avec les deux choix de numéro. **Désactivé volontairement en production tant qu'il n'y a pas de vrai compte**, pour ne jamais proposer un bouton qui n'enverrait rien.
- [x] **E-mail réel** (Gmail officiel de DJAFAT) — `EMAIL_PROVIDER=smtp`, `SMTP_USER=djafat235@gmail.com` et `SMTP_PASSWORD` (mot de passe d'application) en place en production depuis le 23 nov. Testé en vrai : inscription FEAT-020 → code reçu dans une vraie boîte Gmail → compte créé.
- [ ] **Stockage objet (photos)** — l'image MinIO (`quay.io/minio/minio`) reste verrouillée sur les deux registres publics (quay.io **et** Docker Hub, retesté le 23 nov. : toujours 401/accès refusé sur les deux). Il faut soit un compte MinIO payant, soit une alternative compatible S3 (ex. Garage, SeaweedFS) dans `docker-compose.prod.yml`. Sans ça, l'upload de vraies photos de restaurants/plats (resto.djafat.com) ne fonctionne pas — actuellement hors périmètre démo.
- [ ] **Connecteur API Airtel Money officiel (FEAT-019)** — une fois l'accès obtenu, remplacerait le rapprochement manuel actuel (déjà fonctionnel, juste manuel) par une confirmation automatique.

## Phase 2 — pilote à N'Djamena

4 à 6 semaines dans quelques quartiers. On démarre quand : le site et l'app
livreur marchent sur de vrais téléphones, le serveur est en ligne avec les tests
au vert, les contrats sont signés et les numéros marchands actifs.

| Chiffre suivi                                | Objectif proposé |
| -------------------------------------------- | ---------------- |
| Commandes livrées sans incident              | 95 % ou plus     |
| Délai moyen de livraison                     | moins de 45 min  |
| Écart d'espèces chez les livreurs            | 0 FCFA           |
| Transferts Airtel rapprochés automatiquement | 90 % ou plus     |

## Phase 3 — après le pilote

5. Autres villes (Moundou, Abéché…)
