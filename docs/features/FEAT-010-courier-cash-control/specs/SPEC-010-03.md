# SPEC-010-03 — Consulter l'argent détenu par un livreur

## Comportement observable

- `GET /v1/couriers/me/cash` (livreur) → `{ held: { minor, currency }, ceiling: { minor, currency }, blocked }`.
- `GET /v1/deliveries/couriers/:courierId/cash` (équipe) → même réponse pour ce livreur.

## Règles métier

- R1 — `held` vient du grand livre (SPEC-010-01 R1), en XAF au lancement ; `blocked` est l'état enregistré (`cash_blocked_at`).

## Scénarios

### SPEC-010-03-SC01 — vue du livreur

Critères : FEAT-010-AC05

- **Étant donné** un livreur détenant 31 000 XAF, plafond 30 000, bloqué
- **Quand** il consulte
- **Alors** la réponse vaut `held 31000 XAF`, `ceiling 30000 XAF`, `blocked true`

### SPEC-010-03-SC02 — autorisations [evidence: manual]

Critères : FEAT-010-AC05

- **Étant donné** un client connecté
- **Quand** il appelle la route de l'équipe
- **Alors** 403 ; voir `e2e-demo.md`

## Erreurs et cas limites

Un livreur sans aucune écriture détient 0.
