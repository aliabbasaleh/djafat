# FEAT-008 — Clarifications (grill-me)

Questions de conception tranchées par l'agent, dans le cadre fixé par
l'utilisateur le 2026-11-07 (WhatsApp d'abord, zéro dépense, le numéro comme
identifiant, place réservée aux autres méthodes). Aucune question bloquante n'est ouverte.

| ID           | Question                                                                                                   | Bloquant | Statut    | Décision (qui, quand)                                                                                                                                                                                                                                                                           | Specs       |
| ------------ | ---------------------------------------------------------------------------------------------------------- | -------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| FEAT-008-Q01 | Le message pré-rempli du client suffit-il à le connecter (« reverse OTP ») ?                               | oui      | tranchée  | Non. Un escroc peut faire envoyer ce message par sa victime (lien piégé) et être connecté sur son propre appareil. DJAFAT répond avec un code que seul le propriétaire du numéro voit. (agent, validé par l'utilisateur, 2026-11-07)                                                            | SPEC-008-02 |
| FEAT-008-Q02 | Que faire d'un message qui ne demande pas de code (« bonjour », question) ?                                | non      | hypothèse | Ignoré (rien n'est envoyé). Le support ou la commande par WhatsApp est une feature à part.                                                                                                                                                                                                      | SPEC-008-02 |
| FEAT-008-Q03 | Un numéro non tchadien peut-il obtenir un code ?                                                           | non      | hypothèse | Oui s'il est valide (E.164), comme la saisie des numéros de FEAT-005 qui accepte déjà le format international : la diaspora commande pour sa famille, et la réponse est gratuite. Un numéro invalide est ignoré. (Révisé pendant l'implémentation : la première réponse contredisait FEAT-005.) | SPEC-008-02 |
| FEAT-008-Q04 | Le code WhatsApp et le code SMS d'un même numéro partagent-ils limites et verrou ?                         | non      | hypothèse | Oui : même personne, même numéro. Un code WhatsApp ne peut pas servir sur la route SMS et inversement (canal enregistré avec le code).                                                                                                                                                          | SPEC-008-02 |
| FEAT-008-Q05 | Comment éviter qu'une vague de messages fasse payer DJAFAT au-delà des 1 000 réponses gratuites par mois ? | non      | hypothèse | Plafond global de codes WhatsApp par heure (`WHATSAPP_MAX_CODES_PER_HOUR`, 300 par défaut) en plus de la limite par numéro.                                                                                                                                                                     | SPEC-008-02 |
| FEAT-008-Q06 | Meta relivre un message (nouvelle tentative) : un deuxième code ?                                          | non      | hypothèse | Non : l'identifiant du message est retenu 24 h (Redis). Si Redis est indisponible, un doublon reste inoffensif (nouveau code, même limite par numéro).                                                                                                                                          | SPEC-008-02 |
| FEAT-008-Q07 | Un message très ancien livré en retard doit-il produire un code ?                                          | non      | hypothèse | Non au-delà de 10 minutes : le client a sûrement redemandé depuis.                                                                                                                                                                                                                              | SPEC-008-02 |
| FEAT-008-Q08 | Quelles méthodes futures réserver ?                                                                        | non      | hypothèse | Le registre est une liste ordonnée d'entrées `{ id, available, … }` : Facebook, Apple, Google s'y ajouteront chacune avec sa feature. Sur iPhone, Apple exige une connexion « Se connecter avec Apple » si Facebook ou Google est proposé.                                                      | SPEC-008-01 |
| FEAT-008-Q09 | Couper le SMS empêche-t-il le démarrage en production ?                                                    | non      | hypothèse | Non si WhatsApp Cloud est configuré. Sinon le démarrage est refusé : personne ne pourrait se connecter.                                                                                                                                                                                         | SPEC-008-01 |
