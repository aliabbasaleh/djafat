# SPEC-008-03 — Se connecter avec le code reçu sur WhatsApp

## Comportement observable

`POST /v1/auth/whatsapp/verify { phone, code }` (public, numéro saisi à la tchadienne comme FEAT-005) →
200 avec la même réponse que `POST /v1/auth/otp/verify` : `{ access, refresh, user, … }`.

## Règles métier

- R1 — Le code est vérifié sur le canal `whatsapp` : un code SMS ne passe pas ici, et inversement.
- R2 — Comme pour le SMS, le numéro prouvé crée le compte s'il n'existe pas, et il est marqué vérifié.
- R3 — Session ouverte par le même chemin que les autres connexions : contrôle du statut, session, jeton, audit.
