# SPEC-022-09 — La liste des quartiers

## Comportement observable

Aujourd'hui aucune liste de quartiers n'existe ; les données de référence (`apps/api/prisma/reference-data.ts`,
chargées à chaque installation) ont déjà des repères de N'Djamena (FEAT-018). Après (décision
FEAT-022-Q02) : les formulaires livreur et restaurant proposent une liste de quartiers que DJAFAT
modifie dans la console admin, plus « Autre » avec le nom saisi.

## Règles métier

- R1 — La liste est chargée avec les données de référence (quartiers de N'Djamena, voir Migrations) ;
  une installation suivante ajoute les nouveaux noms sans rétablir un quartier qu'un administrateur a
  désactivé ou renommé.
- R2 — Les formulaires montrent les quartiers actifs, triés par nom, puis « Autre ».
- R3 — « Autre » demande le nom (2 à 60 caractères) ; il est gardé tel quel à côté du dossier
  (`neighbourhood_other`) et apparaît dans la console admin pour qu'un administrateur puisse
  l'ajouter à la liste.
- R4 — Console admin : ajouter, renommer, désactiver un quartier (jamais supprimer : des dossiers y
  renvoient) ; deux quartiers actifs ne peuvent pas avoir le même nom (sans tenir compte des accents
  ni des majuscules).
- R5 — La liste est publique en lecture (formulaire d'inscription, sans session).

## Scénarios

### SPEC-022-09-SC01 — les formulaires lisent la liste active

Critères : FEAT-022-AC03, FEAT-022-AC04

- **Étant donné** les quartiers Moursal, Klémat, Chagoua actifs et Abena désactivé
- **Quand** le formulaire demande la liste (`GET /geo/neighbourhoods?city=ndjamena`)
- **Alors** Chagoua, Klémat, Moursal, dans cet ordre, sans Abena

### SPEC-022-09-SC02 — « Autre » garde le nom saisi

Critères : FEAT-022-AC03

- **Étant donné** un livreur qui choisit « Autre » et saisit « Gassi Est »
- **Quand** son inscription est confirmée
- **Alors** son dossier a `neighbourhood_other = 'Gassi Est'` et aucun quartier, et la console admin
  le montre parmi les noms à ajouter

### SPEC-022-09-SC03 — l'administrateur modifie la liste

Critères : FEAT-022-AC03, FEAT-022-AC04

- **Étant donné** un administrateur
- **Quand** il ajoute « Gassi Est », puis essaie d'ajouter « gassi est », puis désactive Abena
- **Alors** le premier est créé, le second refusé (409 `NEIGHBOURHOOD_EXISTS`), Abena n'est plus
  proposé mais les dossiers qui y renvoient le gardent

### SPEC-022-09-SC04 — une réinstallation ne défait rien

Critères : FEAT-022-AC03, FEAT-022-AC04

- **Étant donné** Abena désactivé et Moursal renommé « Moursal Centre » par un administrateur
- **Quand** les données de référence sont rechargées (nouvelle installation)
- **Alors** Abena reste désactivé et « Moursal Centre » garde son nom ; un nom ajouté aux données de
  référence apparaît

## Erreurs et cas limites

409 `NEIGHBOURHOOD_EXISTS` ; un nom vide ou de plus de 60 caractères : 422 ; un `neighbourhoodId`
inconnu ou désactivé à l'inscription : 422.

## Contrats API et données

_Nouveau_ : table `neighbourhoods` (ville, nom, actif, création) ; `GET /geo/neighbourhoods?city=`
(module `geo`, public) ; `POST /admin/neighbourhoods`, `PATCH /admin/neighbourhoods/:id` (module
`admin`). Données de référence : `apps/api/prisma/reference-data.ts`.

## Autorisations

Lecture publique ; modification `admin`, `super_admin`.

## UI et accessibilité

Liste déroulante avec « Autre » en dernier ; console admin : une page « Quartiers » (tableau, champ
d'ajout, actions renommer et désactiver).

## Références visuelles

N/A — les maquettes VIS02 et VIS03 montrent la liste déroulante ; pas de maquette pour la page admin.

## Migrations

Création de `neighbourhoods`, chargée avec les quartiers de N'Djamena des données de référence.
Retour en arrière : supprimer la table après avoir retiré les colonnes qui y renvoient (SPEC-022-02,
03).

## Hypothèses et questions ouvertes

La première liste reprend les quartiers courants de N'Djamena (Moursal, Klémat, Chagoua, Farcha,
Diguel, Dembé, Sabangali, Paris-Congo, Ridina, Gassi, Abena, Atrone, Walia, Amriguébé, Goudji,
Kabalaye, Milezi, Ndingangali, Habbena, Toukra…) ; DJAFAT la corrige dans la console (FEAT-022-Q12,
hypothèse).
