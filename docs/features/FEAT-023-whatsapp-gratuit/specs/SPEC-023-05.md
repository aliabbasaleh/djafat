# SPEC-023-05 — Se connecter avec WhatsApp sur le site et l'application client

## Comportement observable

Sur « Mon compte » (site, `apps/web` `/compte`) et dans l'application client (`apps/mobile`),
« WhatsApp » dans « ou recevoir un code » — et dans « Recevoir le code par » d'un nouvel appareil —
affiche le code à envoyer (FEAT-023-VIS02), puis attend le message et se connecte tout seul.

Aujourd'hui (FEAT-008) l'écran demande le numéro, ouvre WhatsApp sur « Code DJAFAT » et attend que
le client tape le code reçu en réponse (`apps/web/src/components/account/LoginPanel.tsx:208-246`,
`:388-440` ; `apps/mobile/components/account/LoginForm.tsx:209-240`, `:353-400`) ; le nouvel
appareil fait de même (`LoginPanel.tsx:143-205`).

## Règles métier

- R1 — L'écran WhatsApp, dans cet ordre : le titre « Se connecter avec WhatsApp » ; « 1. Appuyez
  sur le bouton : WhatsApp s'ouvre avec ce message déjà écrit : » et le message (SPEC-023-01 R3) ;
  « 2. Envoyez-le, puis revenez ici. » ; l'avertissement « N'envoyez ce code que pour vous
  connecter vous-même. Si quelqu'un vous demande de l'envoyer, refusez : il veut entrer dans votre
  compte. » ; le bouton « Ouvrir WhatsApp » (le lien de SPEC-023-01 R4) ; « Sur un ordinateur :
  envoyez ce message depuis votre téléphone au numéro WhatsApp de DJAFAT, <numéro> » (numéro
  écrit `+235 66 86 89 73`) ; « ⏳ En attente de votre message… (valable 5 min) » (la durée qui
  reste, en minutes) ; « ← Autre moyen de connexion ». Plus de champ « Numéro de téléphone » : le
  numéro est celui qui écrit.
- R2 — L'écran demande où en est son code (SPEC-023-03) toutes les 2 secondes, et tout de suite
  quand il redevient visible (retour de WhatsApp) ; il s'arrête à une issue, à la fin de validité,
  ou en quittant cette vue. Une erreur de réseau ne l'arrête pas.
- R3 — Connecté : comme toute connexion (retour à la page d'où l'on venait, FEAT-020).
- R4 — Numéro confirmé sur aucun compte : « Ce numéro n'est confirmé sur aucun compte », avec
  « Créer un compte » (ouvre « Créer un compte », formulaire client, numéro qui a écrit déjà
  rempli) et « Se connecter par e-mail » (retour à l'e-mail et au mot de passe).
- R5 — Expiré : « Ce code a expiré. » avec « Nouveau code » (un nouveau code, même vue).
- R6 — Nouvel appareil : même vue ; « Se souvenir de cet appareil » reste proposé et part avec la
  demande ; « autre numéro » dit « Ce message ne vient pas du numéro de votre compte. Envoyez-le
  depuis ce numéro. » avec « Nouveau code ». Le bouton de retour dit « Recevoir le code par
  e-mail » (il revient au code déjà envoyé par e-mail) _(v2, 2026-11-28, revue n° 16)_.
- R7 — WhatsApp éteint : « Bientôt disponible », inchangé (FEAT-020-Q05).
- R8 — Application client : « Ouvrir WhatsApp » ouvre WhatsApp (`Linking`) ; l'attente reprend
  quand l'application revient au premier plan.
- R9 — Accessibilité : en arrivant sur la vue, le titre prend le focus ; l'attente puis l'issue
  sont annoncées par **une seule** région vivante (`role="status"`), présente dès l'arrivée, dont
  seul le texte change ; l'avertissement n'est pas une région vivante ; « Ouvrir WhatsApp » est un
  lien nommé, ses émojis ne sont pas lus ; le code est lisible chiffre par chiffre. Applications
  natives : le titre prend le focus, l'attente et les issues sont annoncées sur Android et iPhone,
  une erreur est une alerte _(v2, 2026-11-28, revue n° 10 et 11)_.

## Scénarios

### SPEC-023-05-SC01 — la vue WhatsApp : textes et ordre

Critères : FEAT-023-AC01, FEAT-023-AC08

- **Étant donné** WhatsApp en service et un code `482915` valable 5 min
- **Quand** le client choisit « WhatsApp » dans « ou recevoir un code »
- **Alors** la vue montre, dans l'ordre de R1, le titre, les deux étapes avec « Je me connecte à
  DJAFAT : 482915 (n'envoyez ce code que pour vous connecter vous-même) », l'avertissement,
  « Ouvrir WhatsApp », le numéro de DJAFAT écrit `+235 66 86 89 73`, « En attente de votre
  message… (valable 5 min) » et « ← Autre moyen de connexion » ; aucun champ de numéro.

### SPEC-023-05-SC02 — en attente, puis connecté tout seul

Critères : FEAT-023-AC02

- **Étant donné** la vue WhatsApp affichée
- **Quand** les réponses successives sont « en attente », puis la session
- **Alors** l'écran redemande toutes les 2 secondes, puis s'arrête et connecte le client comme une
  autre connexion ; une erreur de réseau entre deux demandes ne l'arrête pas.

### SPEC-023-05-SC03 — numéro confirmé sur aucun compte : deux boutons, numéro rempli

Critères : FEAT-023-AC03

- **Étant donné** la réponse « numéro confirmé sur aucun compte » pour `+33612345678`
- **Quand** l'écran l'affiche, puis le client appuie sur « Créer un compte »
- **Alors** « Ce numéro n'est confirmé sur aucun compte », « Créer un compte » et « Se connecter par
  e-mail » ; « Créer un compte » ouvre le formulaire client avec `+33612345678` dans « Numéro de
  téléphone » ; « Se connecter par e-mail » revient à l'e-mail et au mot de passe.

### SPEC-023-05-SC04 — code expiré : nouveau code

Critères : FEAT-023-AC01

- **Étant donné** la réponse « expiré »
- **Quand** le client appuie sur « Nouveau code »
- **Alors** « Ce code a expiré. » laisse place à un nouveau code et à une nouvelle attente.

### SPEC-023-05-SC05 — nouvel appareil par WhatsApp

Critères : FEAT-023-AC01, FEAT-023-AC02

- **Étant donné** une connexion par mot de passe sur un appareil inconnu, au numéro confirmé
- **Quand** le client choisit WhatsApp dans « Recevoir le code par », coche « Se souvenir de cet
  appareil » et envoie le message
- **Alors** la vue WhatsApp s'affiche pour cette connexion ; la session s'ouvre et l'appareil est
  mémorisé ; un message venu d'un autre numéro donne « Ce message ne vient pas du numéro de votre
  compte. Envoyez-le depuis ce numéro. »

### SPEC-023-05-SC06 — WhatsApp éteint : « Bientôt disponible »

Critères : FEAT-023-AC06

- **Étant donné** WhatsApp indisponible sur le déploiement
- **Quand** « Mon compte » s'affiche
- **Alors** WhatsApp est grisé « Bientôt disponible » et ne demande aucun code.

### SPEC-023-05-SC07 — les écrans réels [evidence: manual]

Critères : FEAT-023-AC01, FEAT-023-AC02, FEAT-023-AC03

- **Étant donné** l'API, le site et l'application client (version web) sur un poste, et un message
  simulé (SPEC-023-08 R4)
- **Quand** on se connecte par WhatsApp, avec un numéro connu puis un numéro inconnu, en 390×844
- **Alors** les captures `exec-SPEC-023-05-*` montrent la vue de R1, la connexion, et l'issue de R4.

## Erreurs et cas limites

- 503 `WHATSAPP_UNAVAILABLE` à la demande du code : « WhatsApp n'est pas disponible pour le
  moment. » (`accountErrorMessage`, `packages/sdk/src/account-form.ts:214`).
- 429 `RATE_LIMITED`, 403 `ACCOUNT_INACTIVE` : le message de `accountErrorMessage`, l'attente
  s'arrête.
- Quitter la vue (« ← Autre moyen de connexion », autre onglet) arrête l'attente.

## Contrats API et données

Routes de SPEC-023-01 et SPEC-023-03, par le SDK (`packages/sdk/src/auth.ts`) : _nouveau_
`startWhatsapp`, `whatsappStatus` ; _retiré_ la branche WhatsApp de `verifyPhoneLoginCode`.
_nouveau_ `packages/sdk/src/whatsapp-login.ts` : les textes de R1, R4 à R6, la durée qui reste, le
numéro écrit, l'attente (R2) — partagés par les cinq applications.
