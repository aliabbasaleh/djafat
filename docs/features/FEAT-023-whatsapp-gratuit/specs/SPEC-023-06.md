# SPEC-023-06 — Confirmer son numéro par WhatsApp — « Mon profil » et juste après l'inscription

## Comportement observable

Un compte confirme son numéro en envoyant, depuis ce numéro, le message déjà écrit qui porte un
code (SPEC-023-01 R3). Deux endroits :

- « Mon profil » → « Téléphone » → « Confirmer par WhatsApp » (site) ;
- juste après l'inscription, une fois le code de l'e-mail accepté, pour un **numéro étranger** :
  l'étape « Confirmer mon numéro par WhatsApp » (FEAT-023-VIS03), que l'on peut passer (site et
  application client).

Aujourd'hui, « Confirmer par WhatsApp » ouvre « Code DJAFAT » et demande le code reçu en réponse
(`apps/web/src/components/account/PhoneSection.tsx:38-66`, `phone-link.service.ts:31-59`) ; après
le bon code de l'inscription, la session s'ouvre et le site repart (`RegisterPanel.tsx:226-240`,
`apps/mobile/components/account/RegisterForm.tsx:256-262`), sans étape.

## Règles métier

- R1 — « Mon profil » : « Confirmer par WhatsApp » demande un code de confirmation
  (`POST /me/phone/whatsapp`) et affiche la vue WhatsApp (SPEC-023-05 R1) avec le titre
  « Confirmer mon numéro par WhatsApp », le message de confirmation, « 2. Envoyez-le depuis ce
  numéro, puis revenez ici. », « ⏳ En attente de votre message… » et « Retour ». Numéro confirmé :
  le profil est relu et dit « Confirmé ✓ ». « Confirmer par SMS » ne change pas.
- R2 — Message venu d'un autre numéro : « Ce message ne vient pas du numéro de votre compte
  (<numéro>). Envoyez-le depuis ce numéro. » avec « Nouveau code ». Expiré : « Ce code a expiré. »
  avec « Nouveau code ».
- R3 — Après l'inscription : si le numéro du compte est étranger (pas un numéro du Tchad, FEAT-024)
  et que WhatsApp est en service, l'étape « Confirmer mon numéro par WhatsApp » s'affiche :
  « ✅ Votre compte est créé. », « Votre numéro <numéro> ne reçoit pas de SMS. Confirmez-le par
  WhatsApp pour vous connecter ensuite par WhatsApp. », la vue de R1 et « Plus tard ». Pour les
  trois types de compte (client, livreur, restaurant).
- R4 — « Plus tard », ou le numéro confirmé : l'inscription se termine comme aujourd'hui — client :
  retour à la page d'où il venait ; livreur ou restaurant : l'écran « et maintenant ? »
  (SPEC-022-02 R6, SPEC-022-03 R4). « Mon profil » garde « Confirmer par WhatsApp » tant que le
  numéro n'est pas confirmé.
- R5 — Numéro du Tchad, ou WhatsApp éteint : pas d'étape ; l'inscription se termine comme
  aujourd'hui.
- R6 — La session de l'inscription est gardée dès le bon code (la confirmation est une route
  connectée).

## Scénarios

### SPEC-023-06-SC01 — « Mon profil » : confirmé par WhatsApp

Critères : FEAT-023-AC05

- **Étant donné** un compte connecté, numéro `+33612345678` non confirmé, WhatsApp en service
- **Quand** il appuie sur « Confirmer par WhatsApp » et que le message arrive de ce numéro
- **Alors** la vue montre « Confirmer mon numéro par WhatsApp » et « Je confirme mon numéro sur
  DJAFAT : <code> (n'envoyez ce code que pour votre propre compte) » ; puis « Confirmé ✓ ».

### SPEC-023-06-SC02 — « Mon profil » : autre numéro

Critères : FEAT-023-AC05

- **Étant donné** la vue de confirmation
- **Quand** la réponse est « autre numéro »
- **Alors** « Ce message ne vient pas du numéro de votre compte (+33 6 12 34 56 78). Envoyez-le
  depuis ce numéro. » et « Nouveau code » ; le numéro reste « Non confirmé ».

### SPEC-023-06-SC03 — inscription au numéro étranger : l'étape, puis confirmé

Critères : FEAT-023-AC10

- **Étant donné** une inscription client au numéro `+33612345678`, WhatsApp en service
- **Quand** le code de l'e-mail est accepté
- **Alors** l'étape « Confirmer mon numéro par WhatsApp » s'affiche avec « ✅ Votre compte est
  créé. » et « Plus tard » ; le message arrivé, le numéro est confirmé et le client repart vers la
  page d'où il venait ; il se connecte ensuite par WhatsApp (SPEC-023-02 SC02).

### SPEC-023-06-SC04 — « Plus tard »

Critères : FEAT-023-AC10

- **Étant donné** l'étape affichée après une inscription livreur au numéro étranger
- **Quand** il appuie sur « Plus tard »
- **Alors** l'écran « et maintenant ? » du livreur s'affiche ; le numéro reste non confirmé ; la
  session est ouverte.

### SPEC-023-06-SC05 — numéro du Tchad ou WhatsApp éteint : pas d'étape

Critères : FEAT-023-AC10

- **Étant donné** une inscription au numéro `+23566123456`, puis une au numéro étranger avec
  WhatsApp éteint
- **Quand** le code de l'e-mail est accepté
- **Alors** pas d'étape : l'inscription se termine comme aujourd'hui.

### SPEC-023-06-SC06 — les écrans réels [evidence: manual]

Critères : FEAT-023-AC05, FEAT-023-AC10

- **Étant donné** l'API et le site sur un poste, un message simulé (SPEC-023-08 R4)
- **Quand** on s'inscrit au numéro étranger, puis on confirme par « Mon profil » un autre compte
- **Alors** les captures `exec-SPEC-023-06-*` (390×844) montrent l'étape (FEAT-023-VIS03) et
  « Confirmé ✓ ».

## Erreurs et cas limites

- 409 `PHONE_ALREADY_CONFIRMED` : le profil est relu (le numéro a été confirmé ailleurs).
- 503 `WHATSAPP_UNAVAILABLE`, 429, 423 : message de `accountErrorMessage`, l'étape garde
  « Plus tard ».

## Contrats API et données

`POST /v1/me/phone/whatsapp` (SPEC-023-01), `POST /v1/auth/whatsapp/status` (SPEC-023-03),
`GET /v1/me` (relu). SDK : _nouveau_ `startPhoneWhatsapp` ; _retiré_ `verifyPhone('whatsapp', …)`.
`phoneKind` (`@djafat/core`, FEAT-024) dit si un numéro est étranger.

## Autorisations

Compte connecté ; la confirmation ne vaut que pour le numéro du compte, envoyé depuis ce numéro.

## UI et accessibilité

Mêmes règles que SPEC-023-05 R9 ; l'étape d'inscription donne le focus à son titre ; « Plus tard »
est un bouton secondaire.

## Références visuelles

FEAT-023-VIS03 (attendu, faisant-foi) : R3 (textes de l'étape, présence de « Plus tard »), R4.

## Migrations

N/A — aucune.

## Hypothèses et questions ouvertes

- L'étape vaut pour les trois types de compte (FEAT-023-Q15).
- Pas d'étape pour un numéro du Tchad : la question portait sur les numéros étrangers ; « Mon
  profil » reste le moyen pour les autres (FEAT-023-Q04).
