# SPEC-021-04 — Application livreur : connexion par e-mail et mot de passe

## Comportement observable

L'écran de connexion de l'application livreur (`apps/courier/app/(auth)/login.tsx`, téléphone et
navigateur) ouvre sur e-mail et mot de passe (maquette FEAT-021-VIS02), titre « DJAFAT Livreur »,
sous-titre « Connexion livreur. ». Les règles sont celles de SPEC-021-02 ; l'accès reste
`hasCourierAccess` et le refus « Ce compte n'est pas enregistré comme livreur DJAFAT. ».

## Règles métier

- R1 — Mêmes états que SPEC-021-03 R1 : identifiants, code si appareil inconnu, mot de passe
  oublié, et l'écran actuel téléphone puis code quand le SMS est disponible.
- R2 — Le jeton d'appareil est gardé avec le même stockage que la session
  (`apps/courier/lib/auth-storage.ts` : trousseau du téléphone, `localStorage` dans le navigateur),
  sous `djafat_courier_device`, et n'est pas effacé à la déconnexion.
- R3 — Boutons et champs aux tailles de l'application actuelle (gros boutons pour un usage en
  mouvement).

## Scénarios

### SPEC-021-04-SC01 — connexion sur un appareil mémorisé

Critères : FEAT-021-AC03

- **Étant donné** un livreur avec mot de passe, sur un appareil déjà mémorisé
- **Quand** il saisit son e-mail et son mot de passe
- **Alors** il arrive sur l'accueil livreur sans code

### SPEC-021-04-SC02 — appareil inconnu : code par e-mail

Critères : FEAT-021-AC03

- **Étant donné** le même livreur sur un nouvel appareil
- **Quand** il saisit son e-mail et son mot de passe
- **Alors** l'écran du code montre l'adresse masquée ; le bon code avec « Se souvenir de cet
  appareil » le connecte

### SPEC-021-04-SC03 — mauvais mot de passe

Critères : FEAT-021-AC03

- **Étant donné** un mauvais mot de passe
- **Quand** il valide
- **Alors** « E-mail ou mot de passe incorrect. » s'affiche et rien n'est gardé

### SPEC-021-04-SC04 — compte sans le rôle livreur

Critères : FEAT-021-AC03

- **Étant donné** un compte client avec mot de passe
- **Quand** il se connecte à l'application livreur
- **Alors** « Ce compte n'est pas enregistré comme livreur DJAFAT. » et rien n'est gardé

### SPEC-021-04-SC05 — mot de passe oublié [evidence: manual]

Critères : FEAT-021-AC04

- **Étant donné** un livreur à l'e-mail vérifié
- **Quand** il suit « Mot de passe oublié ? » jusqu'au nouveau mot de passe
- **Alors** il est connecté ; captures d'exécution dans le navigateur à l'appui

### SPEC-021-04-SC06 — SMS et WhatsApp grisés tant qu'ils ne sont pas configurés [evidence: manual]

Critères : FEAT-021-AC05

- **Étant donné** le serveur avec le SMS coupé et sans WhatsApp
- **Quand** l'écran s'affiche
- **Alors** SMS et WhatsApp sont grisés « Bientôt disponible » (capture 390×844 dans le navigateur)

## UI et accessibilité

Libellés visibles, `textContentType`/`autoComplete` (`emailAddress`/`email`, `password`,
`oneTimeCode`), `accessibilityLabel` sur les boutons, boutons grisés `disabled` avec « Bientôt
disponible » lisible.

## Hypothèses et questions ouvertes

native est vérifiée par le typage et les tests de logique (FEAT-021-Q07).

- SC05, SC06 : captures de l'application dans le navigateur (`expo export --platform web`).
